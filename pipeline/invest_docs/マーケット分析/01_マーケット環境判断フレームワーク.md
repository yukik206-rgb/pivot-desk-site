# マーケット環境判断フレームワーク(ミネルヴィニ流)
最終更新: 2026-07-29 / 対象市場: 米国株

個別銘柄のチャート分析(トレンドテンプレート・VCP)は「良い相場」でこそ機能する。ミネルヴィニも「銘柄選びより先に、今が買っていい地合いかどうかを判断する」ことを重視しており、これは自動化システムの**マクロゲート**(全体のON/OFFスイッチ)として組み込むべき層である。関連: [チャート分析/01_ミネルヴィニ投資手法_調査レポート.md](../チャート分析/01_ミネルヴィニ投資手法_調査レポート.md)、[チャート分析/02_自動化システム設計書.md](../チャート分析/02_自動化システム設計書.md)

---

## 1. 分配日(Distribution Day)

**定義**: 主要指数(S&P500・Nasdaq総合など)が、前日出来高を上回る出来高を伴って下落した日。「機関投資家が売っている」ことを示すシグナル。

**カウントルール**
- 直近25営業日(約5週間)以内に分配日が**4〜6日**溜まると、相場は「警戒段階」入りとみなす
- 出来高が前日を下回っている下落日は分配日としてカウントしない(ここが実装上の落とし穴になりやすい)
- **フォロースルーデー直後の数日以内に分配日が出た場合は特に危険**(新しい上昇トレンドの信頼性が低いことを意味する)
- 分配日は時間経過(通常25営業日)とともに古いものから自動的にカウントから外れる(「消滅」する)

## 2. フォロースルーデー(Follow-Through Day)

**定義**: 相場が調整(下落)した後、反発局面の中で、通常「4日目以降」に**前日を上回る出来高で+1.5%程度以上の上昇**を記録した日。新しい上昇トレンドの始まりを示唆する古典的シグナル(オニール由来だが、ミネルヴィニも地合い判断の柱として使用)。

**実務上の使い方**
- フォロースルーデーが出るまでは新規のフルポジション構築を控える
- フォロースルーデー後も、直後の分配日発生には要警戒(「フォロースルーデー→即分配」は失敗しやすいパターン)

## 3. 指数へのステージ分析・トレンドテンプレートの適用

個別銘柄と同じロジックを主要指数(S&P500、Nasdaq総合、必要に応じてラッセル2000)にも適用する:
- 指数が50日線・150日線・200日線の上にあり、かつ200日線が上向き → マクロ環境はStage 2寄り(強気)
- 指数の200日線が横ばい・下向き、50日線が200日線を割り込む(いわゆるデッドクロス方向) → Stage 3〜4寄り(弱気・警戒)

## 4. 地合い別のポジション運用ルール(目安)

| 地合い判定 | 新規建て | ポジションサイズ |
|---|---|---|
| 強気(分配日少・指数がStage2) | 通常通り新規エントリー可 | フル(設計書のリスク計算式どおり) |
| 警戒(分配日4〜6日蓄積 or フォロースルー直後の分配日) | 新規は厳選・スターターポジションのみ | 縮小(例: 通常の50%) |
| 弱気(指数がStage3〜4、分配日多数) | 新規エントリー停止 | 既存ポジションの整理・現金比率を上げる |

## 5. 自動化への統合方針

このフレームワークは設計書(02)の「⑧マクロゲート連携」で、個別銘柄スクリーニング結果に対する**重み付け・フィルタのオン/オフ**として実装する。具体的には:
1. 日次で主要指数の分配日カウント・フォロースルーデー判定・ステージ判定を計算
2. 上記表の3段階(強気/警戒/弱気)いずれかにマーケット状態をラベリング
3. 個別銘柄の候補リストに対し、警戒・弱気時はランキングスコアを減点する、または「新規推奨」から除外し「監視のみ」に格下げする
