# ディープリサーチ: ミネルヴィニ手法の実証根拠と限界
最終更新: 2026-07-31

`01_ミネルヴィニ投資手法_調査レポート.md`・Phase 4バックテスト結果を踏まえ、①RSレーティング近似式の妥当性、②実際の成功事例、③第三者による同種システムの長期検証、の3点を追加調査した。

---

## 1. RSレーティング近似式の妥当性 — 確認できた

`trend_template.py`で採用した近似式は、複数の独立したソース(Stockbeeブログ、GitHub `skyte/relative-strength`等)で一致して報告されている「業界標準の再現式」と完全に一致した。

```
StrengthFactor = 0.4×ROC(63日) + 0.2×ROC(126日) + 0.2×ROC(189日) + 0.2×ROC(252日)
→ ユニバース内でパーセンタイル化(1-99)
```

2024-2025年にかけての公式な計算式変更の報告は見当たらなかった。**実装の妥当性は追加調査でも裏付けられた**。

## 2. ミネルヴィニ自身の実績 — 本物だが「別ゲーム」

- 2021年の米国投資選手権で**監査済み+334%**のリターンを記録し優勝(2度目の優勝)。
- 2025年選手権(9ヶ月時点)でも、450名超の参加者中、$100万部門トップ10のうち6名が彼の顧客・クライアント。
- ドキュメント化された実トレード例: **$XLE(エネルギーセレクトSPDR)を2022年1月4日に購入し、ピークまで+70%超**([TraderLionポッドキャスト](https://creators.spotify.com/pod/profile/traderlion/episodes/33-500-RETURN---Mark-Minervinis-VCP-Setup-that-made-him-Millions-e2pij3r)で言及)。ETFにも同じトレンドテンプレート/VCPロジックを適用している点は興味深い。
- 「33,500%リターン」という有名なエピソードも複数の情報源で言及されているが、**具体的な銘柄名・詳細な検証可能な記録は今回の調査では特定できなかった**(伝聞的な紹介にとどまる)。

**重要な注意**: これらは**裁量トレード**であり、以下の点で私たちの機械的バックテストとは別物:
- 集中投資(推奨銘柄数点への集中、Phase 1-4で検証した「幅広い銘柄への機械的分散」とは真逆)
- ピラミッディング(勝ちポジションへの追加)・利食いの半分利確・建値へのストップ引き上げなど、動的なポジション管理
- おそらくレバレッジの活用
- ブレイクアウトのタイミング・見送り判断における裁量(VCPスコアの閾値だけでなく、出来高の質感・セクター動向・地合いなど定性判断)

→ **「スクリーニング条件を満たす」ことと「ミネルヴィニ本人が出す成績」の間には、実行力(ポジションサイジング・利食い・損切りの技術)という大きなギャップがある**。これは自動化システムが原理的に埋めにくい部分。

## 3. 第三者による同種システムの長期検証 — 重要な比較データ

[crackingmarkets.com: US Stock Momentum Trading System for Retail Traders](https://www.crackingmarkets.com/us-stock-momentum-trading-system-for-retail-traders-deep-research/) より、類似のモメンタム/トレンドフォロー系システムの長期(16-20年)検証結果:

| 指標 | 数値 |
|---|---|
| CAGR(Arthur Hill 15銘柄システム, 2001-2016) | 約14.3% |
| CAGR(Validea 10銘柄モデル, 2003-2023) | 約11.8%(対 S&P500 8.7%) |
| 勝率 | 約57%(43%が損失) |
| 平均利益/平均損失 | 平均利益が平均損失の2.5倍 |
| 最大ドローダウン(200日線フィルターあり) | 20-21% |
| 最大ドローダウン(フィルターなし) | 約45% |
| 累積リターン(2003-2023) | 10倍超(S&P500は6倍) |

**既知の弱点(第三者検証より)**:
1. **モメンタムクラッシュ**: 長期下落後の急反発局面で壊滅的(2009年で-73%の崩壊事例)。V字回復では出遅れた「がれき株」が急騰し、モメンタム/トレンド系はまさにその局面で最も弱い。
2. **高い売買回転率**: 年200-300%の回転 → スリッページ・短期譲渡益課税で数%のリターンが消失しうる。
3. **方向感のない相場での弱さ**。

### 私たちのPhase 4結果との整合性

- 第三者検証の「勝率57%・平均利益が平均損失の2.5倍」という非対称な構造は、私たちのPhase 4で見た「対SPY超過勝率は45-48%とコインフリップ以下だが平均超過リターンはプラス」という歪んだ分布の結果と**方向性が一致**している(少数の大勝ちが平均を牽引する構造)。
- 「2022年を含めるとエッジが縮小した」という私たちの発見は、モメンタム系全般が**下降相場・レジーム転換期に弱い**という第三者研究/アカデミック文献の指摘とも整合的。
- 第三者システムの年率超過リターン(+3-6pt程度)は、私たちのPhase 4(63日超過+0.7〜1.5%程度、年率換算すると近い水準)と**概ね同じオーダー**であり、突飛な数字ではない。

## 4. 総合結論・design docへの追加事項

- **手法自体の「エッジ」は実在するが、規模は控えめ**(年率数ポイント程度)というのが、私たち自身の検証と第三者検証の両方が示す一致した絵。ミネルヴィニ本人の実績は、これに「卓越した実行力」が掛け合わさった結果と考えるのが妥当。
- **Phase 4の既知の限界に追加すべき項目**:
  - 取引コスト・スリッページ・売買回転率を考慮していない(現状のバックテストは理論上のグロスリターン)
  - 短期譲渡益課税の影響を考慮していない
  - モメンタムクラッシュ(急落後の急反発)への耐性を検証していない — 2020年3月のようなV字回復局面を含む期間での個別検証が望ましい
  - 自動化システムは裁量トレードの「利食い・損切りの技術」を再現できていない(固定期間リターンで評価しているのみ)
